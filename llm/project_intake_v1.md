# Project Intake (v1)

Defines the **entry point** of a project.

---

## Purpose

Capture all required context to enable structured work.

---

## Required Information

- Objective
- Scope (explicit boundaries)
- Constraints
- Known unknowns
- Initial artifacts (if any)

---

## Rules

- Missing critical information -> STOP
- No implicit scope allowed
- All inputs must be written

---

## Output

A structured intake artifact usable by downstream blocks.
